# 毛概刷题系统

这是基于两份毛概 Excel 题库重构后的静态刷题系统：

- `毛概系统题库_合并终版.xlsx`：全量题库，786 题，默认题库范围。
- `毛概重点题库_章节题型整理版.xlsx`：核心重点题库，154 题，专项刷题范围。

当前题库架构为：

- 题库范围：`全量题库 / 核心重点题库`
- 知识分类树：来自题库的章节字段
- 题型：`单选 / 多选 / 判断`

系统已永久移除自动复习排期逻辑。错题本只保留错题归档、筛选、手动标记掌握状态和导出。

## 访问方式

GitHub Pages：

```text
https://mark-dai-d.github.io/llm-quiz-system/
```

```powershell

```

然后打开：

```text

```

## 默认管理员

```text
用户名：admin
密码：admin123
```

普通用户可自行注册。所有学习数据保存在当前浏览器 `localStorage` 中，不同账号互相隔离。

## 核心功能

- 题库范围切换：全量题库、核心重点题库；刷题、错题、收藏、统计、考点提炼均按当前范围独立计算。
- 题型多选：单选、多选、判断。
- 知识分类树：按章节展示分类节点与题量，默认展开一级章节。
- 刷题模式：章节专项、阶梯式刷题、薄弱章节、全真随机、错题专项。
- 答题页：上一题、下一题、答案修改、本轮状态持久化。
- 错题本：错误次数、手动已掌握/未掌握、Word/PDF 导出。
- 收藏、单题备注、考点提炼、学习统计、章节正确率排行。
- 快速开始刷题：记忆上次题库范围、刷题模式和题量配置，一键开刷。
- 键盘快捷键：答题页按 `A/B/C/D` 选择选项，按 `Enter` 提交。
- 单选/多选新开刷题轮次自动随机打乱选项，同一轮内顺序稳定，判分仍按原始选项 ID 精准计算。
- 备注富文本：文字加粗、本地图片上传、剪贴板图片粘贴，图片自动压缩并适配手机/电脑宽度。
- 备注公开分享：默认私有，可手动公开；其他账号只读查看；“我的公开备注”支持批量关闭公开和批量删除。
- 普通用户全局删除：三级确认、完整审计日志、所有本地账号学习数据联动清理。
- 管理员回收站：删除题目保留 30 天，支持单题/批量恢复；恢复题库内容但不恢复已清理的个人历史。
- 本轮剔除：只跳过当前轮次中的题目，不影响公共题库、错题、收藏和统计。
- Excel 模板导入、当前筛选导出、当前题库导出。
- Excel、Word、打印/PDF 导出可选择是否打乱选项，默认保持题库原始顺序。

## 全局删除说明

当前 GitHub Pages 版本没有服务器数据库。“全局删除”会在**同一浏览器设备**内对公共题库和所有本地注册账号同步生效，并通过 `storage` 事件同步其他已打开的标签页。删除时会清理该题在各账号中的作答记录、错题、收藏、备注、掌握状态和未完成轮次。

不同电脑、手机或浏览器之间无法仅靠 `localStorage` 实时同步。若需要真正跨设备全局删除、回收站和审计日志，应接入 FastAPI + SQLite 或云数据库。

## 公开备注说明

当前版本部署在 GitHub Pages，学习数据使用浏览器 `localStorage`。因此公开备注可在**同一浏览器设备中的不同登录账号之间共享**，不会上传到服务器。

若需要不同电脑、手机或浏览器之间实时共享公开备注，需要后续接入 FastAPI + SQLite、Supabase 等云端数据服务；私有备注仍应继续按账号隔离存储。

## Excel 导入模板

模板文件：

```text
题库导入模板.xlsx
```

系统仅识别包含以下列名的题目表，其他 sheet 会被忽略：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| 章节 | 是 | 用 `/` 分隔多级分类，如 `第一章/第一节` |
| 题型 | 是 | 只能填 `单选` / `多选` / `判断` |
| 题干 | 是 | 题目内容 |
| A-D | 单选/多选必填 | 判断题可填 `正确/错误` |
| 正确答案 | 是 | 单选填 `A`；多选填 `ABC`；判断填 `正确/错误` |
| 解析 | 否 | 题目解析或背诵要点 |
| 易错点标签 | 否 | 可用 `、` 或 `,` 分隔多个标签 |

## 从 Excel 重新生成题库

```powershell
python generate_data.py
```

脚本只读取包含题库字段的“题库”表，忽略统计汇总、使用说明等非题目 sheet。
