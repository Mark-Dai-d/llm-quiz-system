# 大模型省赛刷题系统

这是基于 `大模型应用技术省赛完整备考总题库_570题.xlsx` 重构后的静态刷题系统。当前题库架构为：

- 顶层：`基础层 / 进阶层 / 冲刺层`
- 二级：知识分类树，来自题库的模块与考点
- 题型：`单选 / 多选 / 判断 / 简答`

系统已永久移除自动复习排期逻辑。错题本只保留错题归档、筛选、手动标记掌握状态和导出。

## 访问方式

GitHub Pages：

```text
https://mark-dai-d.github.io/llm-quiz-system/
```

本地运行：

```powershell
python -m http.server 8766
```

然后打开：

```text
http://127.0.0.1:8766/
```

## 默认管理员

```text
用户名：admin
密码：admin123
```

普通用户可自行注册。所有学习数据保存在当前浏览器 `localStorage` 中，不同账号互相隔离。

## 核心功能

- 难度层级单选：全部难度、基础层、进阶层、冲刺层。
- 题型多选：单选、多选、判断、简答。
- 知识分类树：按当前难度层展示分类节点与题量。
- 刷题模式：层级专项、阶梯式刷题、薄弱层级、全真随机、错题专项。
- 答题页：上一题、下一题、答案修改、本轮状态持久化。
- 错题本：错误次数、手动已掌握/未掌握、Word/PDF 导出。
- 收藏、单题备注、考点提炼、学习统计、薄弱层级热力图。
- 备注富文本：文字加粗、本地图片上传、剪贴板图片粘贴，图片自动压缩并适配手机/电脑宽度。
- 备注公开分享：默认私有，可手动公开；其他账号只读查看；“我的公开备注”支持批量关闭公开和批量删除。
- Excel 模板导入、当前筛选导出、全库导出。

## 公开备注说明

当前版本部署在 GitHub Pages，学习数据使用浏览器 `localStorage`。因此公开备注可在**同一浏览器设备中的不同登录账号之间共享**，不会上传到服务器。

若需要不同电脑、手机或浏览器之间实时共享公开备注，需要后续接入 FastAPI + SQLite、Supabase 等云端数据服务；私有备注仍应继续按账号隔离存储。

## Excel 导入模板

模板文件：

```text
题库导入模板.xlsx
```

系统仅识别包含以下列名的题目表，其他 sheet 会被忽略：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| 难度层级 | 是 | 只能填 `基础层` / `进阶层` / `冲刺层` |
| 知识分类 | 是 | 用 `/` 分隔多级分类，如 `模块/章节/小节` |
| 题型 | 是 | 只能填 `单选` / `多选` / `判断` / `简答` |
| 题干 | 是 | 题目内容 |
| 选项A-D | 单选/多选必填 | 判断、简答可留空；选项E/F为兼容扩展列 |
| 标准答案 | 是 | 单选填 `A`；多选填 `ABC`；判断填 `对/错`；简答填参考答案 |
| 解析 | 否 | 题目解析或背诵要点 |

## 从 Excel 重新生成题库

```powershell
python generate_data.py
```

脚本只读取题目表，忽略 `05_高频考点汇总表`、`06_易混知识点对比表`、`07_错题本模板` 等非题目 sheet。
