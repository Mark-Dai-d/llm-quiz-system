# 大模型省赛层级化刷题系统

基于 `大模型应用技术省赛完整备考总题库_570题.xlsx` 生成的个人专用刷题系统，支持 GitHub Pages 静态部署和本地浏览器直接使用。

## 本地运行

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 默认管理员

- 用户名：`admin`
- 密码：`admin123`

普通用户可自行注册。所有学习数据保存在当前浏览器 `localStorage` 中，不同账号相互隔离。

## 主要功能

- 无限级层级树选题：层级专项、阶梯式、薄弱层级、全真随机、错题专项。
- 自定义题量：5/10/20、手动输入、当前筛选下全部题目。
- 答题页：上一题、下一题、答案修改、本轮进度持久化。
- 错题立即进入今日复习，艾宾浩斯排期：6小时、1天、3天、7天、15天。
- 错题本、我的收藏、单题备注、AI式考点提炼、批量背诵提纲。
- 全局统计、层级穿透统计、薄弱层级排行、TOP20 高频错题。
- 本地数据备份/恢复、错题/提纲导出、浏览器打印保存 PDF。

## 更新题库

在项目目录运行：

```powershell
python generate_data.py
```

脚本会读取桌面的 Excel 文件并重新生成 `data.js`。管理员也可以在系统内导入本机题库 JSON 覆盖当前浏览器的数据源。
